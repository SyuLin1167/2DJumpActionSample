ルートの[LICENSE](https://github.com/SyuLin1167/2DGameSample/blob/08f9fa53fa5e9043d46aeede8e7aab7bab519892/LICENSE)はMIT Licenseです。著作権表示は2025 SyuLin1167です。外部ライブラリ・素材の条件は、それぞれの配布物と出典で確認します。

## 確認対象

| 対象 | 現状・公開前に確認するもの |
| --- | --- |
| DxLib | setup.batは3.24f指定。配布元と同梱の利用条件・第三者ライブラリ表記を確認 |
| nlohmann/json | developから取得。使用した版と著作権・ライセンス表示を記録 |
| VitePressと依存パッケージ | docs/package-lock.jsonで固定。配布対象に含まれる依存物のライセンスを確認 |
| Title.png / Play.png / Result.png / bg.png | 制作者、出典、加工・再配布・掲載条件が未整理 |
| map.png / player.png | 同上。ゲーム内利用とサイト掲載を分けて確認 |
| BGM_TestLoop.wav | 制作者・出典・再配布・動画利用条件が未整理 |
| SE_Confirm.wav / SE_Footsteps.wav / SE_Jump.wav | 同上 |

素材が自作か外部素材かも、この一覧だけでは確定していません。すべてMITで自由に再配布できるという説明は行いません。確認済みの素材だけをサイトへ掲載してください。

## 記録する項目

素材名、作者、配布URL、取得日、適用ライセンス、必要な表記、加工の有無、ゲーム配布可否、サイト・動画掲載可否を記録します。情報が確定したらこのページを更新します。

このサイトの初期版はゲーム素材をpublicフォルダーへコピーせず、文章とコードを中心にしています。[掲載素材の計画](./media.md)
