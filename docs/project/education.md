# 教材としての利用

## 目的

C++の基本を学んだ学生が、入力・更新・描画・衝突・資源管理のつながりを読み、自分のゲームを制作できるようにすることを目指します。学校への提供・導入実績は未確認です。

## 授業への組み込み案

1. 導入とサンプル操作：環境・構成・再現手順を記録する。
2. GameObjectとComponent：表示と移動を小さなクラスに分ける。
3. 入力と衝突：移動量、法線、イベントを説明する。
4. アニメーションとSE：読み込みと再生の役割を分ける。
5. シーンとルール：ミニゲームに開始・終了条件を作る。
6. 発展：寿命、非同期、既知の制約を調べて改善案を考える。

回数・時間は授業に合わせて調整する提案です。授業実施済みという意味ではありません。

## 到達確認

動いた画面だけでなく、どのクラスを変更したか、なぜその場所へ処理を置いたか、誰がオブジェクトを破棄するか、どんな入力で確認したかを学生自身が説明します。

## 提供前の準備

担当者は実習コードを同じ環境でビルド・実行し、素材条件を確認します。ゲームの既知の問題と教材上の設計を区別し、未検証箇所を動作保証として案内しません。
