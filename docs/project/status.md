## 利用上の制約

- 対象はWindows、x64・v143。Win32は本ガイドの対象外です。
- setup.batのnlohmann/json取得版が固定されていません。
- 起動時のresourcesコピーはソースのフォルダー配置に依存します。
- 同型Componentは1登録枠で、更新順は追加順ではありません。
- GameObject／Component／アセットの借用ポインタを所有者より長く保持しないでください。
- MapはLoadingContextの存在が前提です。タスクはRun前に登録します。
- Loadingは同一インスタンスの再実行を前提としません。100%進捗は成功保証ではありません。
- コライダー全体のStepは二重ループです。大量オブジェクトでの性能保証はありません。
- 同一カテゴリのコライダー削除は他コライダーのマスク・イベントへ影響する実装です。複数個体への拡張時に確認が必要です。
- Filterは形状ごとにownerIDをOR結合する一方、HasMaskは完全一致検索です。複数タグを合成したマスクの動作は要確認です。
- 唯一のシーンをCmdPopすると空スタックの扱いに問題があります。終了はCmdQuitを使います。
