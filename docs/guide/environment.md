# 開発環境を用意する

## 必要なもの

| 項目 | 準備する内容 |
| --- | --- |
| OS | Windows。コードはWindows APIとDxLibを使用 |
| IDE | Visual Studio 2026 |
| ワークロード | C++によるデスクトップ開発 |
| ビルドツール | MSVC v143のx64/x86ビルドツール |
| SDK | Windows SDK。プロジェクトの指定は10.0 |
| 取得・展開 | Git、curl、PowerShellのExpand-Archive |

Visual Studio Installerでワークロードを追加し、個別コンポーネントにv143が入っていることを確認します。IDEの世代とツールセットは別です。VS2026を使うために、このプロジェクトをv145へ変更する必要はありません。

## 依存ライブラリ

リポジトリ直下の`setup.bat`が、DxLib 3.24fとnlohmann/jsonのヘッダーを`ProjectName/include`へ配置します。インターネット接続が必要です。

nlohmann/jsonはdevelopブランチから取得するため、取得時点で内容が変わります。同じ教材環境を複数人で再現する際は、取得日と使用版を記録してください。版固定は今後の改善候補で、現在のセットアップには実装していません。

## 対象の構成

`Debug | x64`を最初の構成にします。`Release | x64`もv143設定ですが、今回の文書作成では両構成のビルドを実行していません。Win32はこのガイドの動作対象には含めません。

文書サイトを読むためにNode.jsをゲームへ導入する必要はありません。サイトをローカルで構築する場合だけ[文書サイトの開発](../project/documentation.md)を参照してください。
