# ゲーム制作を始める

## 小さな変更から始める

まず元のゲームが動く状態を保存します。移動速度、描画色、ゴール位置など、変化が目で分かる項目を1つずつ変更してください。JSONのキー名は`PlayerData`や`MapInfo`の読み込み実装と照合します。

次に[GameObjectの実習](../tutorials/game-object.md)で、自作の図形を表示します。新しい`.ixx`はファイルを置くだけでなく、Visual Studioのプロジェクトへ追加する必要があります。

## 共通機能とゲーム固有処理

GameObject、Component、シーン、入力、画像・音声は共通の仕組みです。ジャンプ、特定のPlayer、ゴール条件、マップ配置は付属ゲームのルールです。別ジャンルへ応用する際は、まず固有ルールを変え、共通機能の変更を最小限にします。

上から見下ろすゲームへ発展させる場合、縦移動の既知の問題と円対タイルの未対応を先に確認してください。現行コードのまま全方向移動や全形状対応が完成しているとは扱いません。
