# サンプルゲームの操作

| 場面 | 操作・結果 |
| --- | --- |
| タイトル | Startボタンを左クリックすると読み込み画面を経てプレイへ |
| 終了 | タイトルのExitボタンを左クリック |
| 水平移動 | 左右の矢印キー。両方の同時押しは水平方向を相殺 |
| ジャンプ | Space。着地イベントで再びジャンプ可能になる |
| クリア | GOALとの接触でResultへ |
| リザルト | Rでタイトルへ戻る |

ボタンは内部で押下後の左ボタン解放を検出します。押して離すまでをボタン上で行ってください。TitleのソースにはEキーに関する古いコメントがありますが、現在の開始条件はボタンです。

ウィンドウの描画サイズは1920×1080です。画面内に収まらない場合は表示環境を確認してください。可変解像度対応はこのガイドでは保証しません。
