# 利用ガイド

2DGameSampleは、C++とDxLibでゲームの仕組みを学び、実際の制作へ応用するためのサンプルです。現在の付属ゲームはジャンプアクションですが、オブジェクト管理や入力、シーン、画像・音声などはほかの2Dゲームでも使う構成です。

## 学習の順序

1. [開発環境](./environment.md)を用意します。
2. [取得・ビルド・実行](./quickstart.md)を行います。
3. [操作方法](./controls.md)に沿ってサンプルを触ります。
4. [基本構造](./structure.md)と[更新順序](./lifecycle.md)を読みます。
5. [チュートリアル](../tutorials/index.md)で小さな変更から始めます。

## 対象範囲

Windows、Visual Studio 2026、x64・v143を導入の基準にしています。ブラウザーで動くのはこの文書サイトです。ゲーム自体をブラウザーやスマートフォンで動かす構成ではありません。

初めて見る用語は[APIの読み方](../api/index.md)で確認できます。現時点の制約は[実装状況](../project/status.md)を参照してください。
