# 困ったときは

| 症状 | 最初に確認すること |
| --- | --- |
| v143が見つからない | Visual Studio Installerの個別コンポーネント |
| 対象構成でリンクできない | Debug／Release・x64を選んでいるか |
| DxLib.h・json.hppが見つからない | setup.batの実行場所、ダウンロード結果、include配下 |
| import・モジュールのエラー | C++20、v143、ファイルのプロジェクト登録、依存モジュール名 |
| 新しいクラスが表示されない | AddObject、MyObjectTag、Init、Drawの実装 |
| 画像が見つからない | 元のresourcesへの配置、ファイル名、仮想パス |
| 起動時のファイル例外 | 実行ファイルから../../resourcesが存在するか |
| ロードが100%でも進まない | HasFailed、失敗ログ。進捗100%は成功を意味しない |
| アニメーションで例外 | CreateAnimCategory → AddAnim → PlayAnimの順序と名前 |
| 円が地形を通り抜ける | 円対タイルは未対応 |
| 縦移動が設定速度にならない | MoveWithKeyの既知の問題 |

モジュールの変更後に古い中間ファイルが疑われる場合は、Visual Studioでソリューションをクリーンしてリビルドします。関係のないファイルやライブラリを削除する必要はありません。

問題を報告する際は構成・ツールセット・コミット・再現手順・期待結果をまとめます。ログはOS・ハードウェア情報やパスを含むことがあるので、共有する範囲を確認してください。
