## コードの扱い

01〜03は連続した例です。04〜06は既存Playerを参照・変更する実習、07〜08は独立した小さなゲームです。すべてを同時にPlayerへ貼り付ける必要はありません。

新しい`.ixx`はVisual Studioのプロジェクトへ追加し、C++モジュールインターフェースとして扱われることを確認します。ファイル名と`export module`名、利用側の`import`名を一致させてください。

コードは現行APIと照合したものですが、C++コンパイル・実行は未検証です。章末の期待結果を使い、各段階でビルドしてください。エラーが出た段階で、追加したファイルの登録とimportを確認します。
