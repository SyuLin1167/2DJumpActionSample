## 表記と所有権

表の`void`は戻り値なし、`T*`や`T&`は管理対象への参照です。取得したポインタを自分でdeleteしないでください。`shared_ptr`は所有を共有するので、保持すると寿命が延びます。特にGameObjectやComponentを所属シーン外へ持ち出さないでください。

`protected`は派生クラス向けです。例えば`GameObject::m_compMgr`や`ColMgr()`を外部コードから直接使うことはできません。

表内では読みやすさのため関数を短縮表示する場合があります。正確な型・const・テンプレート・オーバーロードは各ページ末尾の全モジュール索引にある**実ソース**を参照します。既存コメントには古い説明があるため、コメント単独では仕様とみなしません。
