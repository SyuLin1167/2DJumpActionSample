# アニメーション・サウンド管理

## 資源と再生を分ける

Animationは分割画像とアニメーション定義、Animatorはオブジェクトごとの現在フレーム・再生状態を管理します。Soundは定義と音声ハンドル、AudioSourceはPlay／Pause／Stopの操作を担当します。

この分割により「読み込む処理」と「毎フレームの再生操作」を別の場所で追えます。Playerはその接続例です。

## 共有に伴う制約

AssetManagerは型ごとに管理クラスを共有し、各資源は文字列の名前で参照します。同じ名前を再読み込み・削除すると、別の利用者にも影響します。アセットごとの参照カウントによる貸出管理ではありません。

AnimationのGetAnimはフレーム配列の借用ポインタを含む値を返します。元画像の寿命を超えて描画できません。AudioSourceのループ再生も元ハンドルを共有するため、同名音の完全に独立した再生状態を保証しません。

## 現在使う範囲

教材では待機・歩行のLOOPアニメーション、歩行ループSE、単発SEを扱います。ONCEアニメーションの終了制御やBGM経路は検証・改善対象です。列挙名や素材ファイルが存在するだけで動作済みとは判断しません。
