# 設計の全体像

このプロジェクトは、ゲーム固有のPlayerやGoalと、それらを支える管理・入力・描画・衝突の仕組みを分けています。ここではコードから確認できる構造と、構造が持つ利点・制約を説明します。作者の未確認の意図や、未測定の性能成果は断定しません。

| テーマ | 読みどころ |
| --- | --- |
| [Modules](./modules.md) | 公開宣言と依存の単位 |
| [コンポーネント](./components.md) | 継承と機能の組合せ |
| [Visitor](./collision.md) | 2つの形状に応じた処理の選択 |
| [非同期処理](./loading.md) | タスク登録、実行、共有状態への反映 |
| [所有権](./ownership.md) | 所有する参照、借用参照、破棄順 |
| [アセット](./assets.md) | 資源と再生状態の分離 |

改善例は[PR #35](https://github.com/SyuLin1167/2DGameSample/pull/35)の差分で確認できます。タスク登録と実行の分離、結果のメインスレッド反映、読み込み失敗処理、世代付きIDの生存検査が追加されています。性能比較や完全な安全性の証明を行った記録ではありません。
